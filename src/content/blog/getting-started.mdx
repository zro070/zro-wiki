## 🌟 Frosti Blog Theme

A minimal, responsive, and feature-rich Astro blog theme designed for creators who value beautiful content presentation and exceptional performance.

- [Explore Blog](/blog)
- [Star on GitHub](https://github.com/EveSunMaple/Frosti)

## ✨ Features

- **Responsive Design** — Fully responsive design that looks great on all devices from mobile to desktop.
- **Dark/Light Mode** — Toggle between light and dark themes with a beautiful transition effect.
- **MDX Support** — Write your content in MDX with full support for custom components and JSX.
- **SEO Optimized** — Built-in SEO optimization with meta tags, OpenGraph, and JSON-LD.
- **Fast Performance** — Optimized for speed with lazy loading, code splitting, and minimal JavaScript.
- **Customizable** — Easily customize the theme to match your personal brand and preferences.

## 🚀 Quick Start

Get started in three simple steps:

### 1. Clone the repository

Use Git to clone the Frosti repository to your local machine:

```sh
git clone --depth 1 https://github.com/EveSunMaple/Frosti.git Frosti
```

### 2. Install dependencies

Navigate to the project directory and install dependencies:

```sh
cd Frosti && pnpm install
```

### 3. Start the development server

Launch the local development server to see your blog:

```sh
pnpm run search:index && pnpm run dev
```

> Check out the [blog section](/blog) for detailed guides and documentation.
